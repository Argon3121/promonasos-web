# Настройка отправки заявок

Форма отправляет письмо на `info@hermetica.su`. Отправитель — `info@hermetica.su` по умолчанию. Для отправки требуется SMTP-доступ к корпоративному почтовому ящику.

## Настройки приложения

Перед запуском задайте переменные окружения в конфигурации запуска IntelliJ IDEA, Docker или сервиса, где работает сайт:

| Переменная | Что указать |
|---|---|
| `SMTP_HOST` | SMTP-сервер почтового провайдера |
| `SMTP_PORT` | Порт SMTP, обычно 587 для STARTTLS или 465 для SSL/TLS |
| `SMTP_USERNAME` | Логин почтового ящика/SMTP |
| `SMTP_PASSWORD` | Пароль или пароль приложения, выданный провайдером |
| `SMTP_FROM` | Разрешённый адрес отправителя; обычно корпоративный адрес из SMTP-аккаунта |
| `SMTP_AUTH` | `true`, если сервер требует авторизацию |
| `SMTP_STARTTLS` | `true` для STARTTLS (обычно порт 587); `false`, если провайдер требует другой режим |
| `SMTP_SSL` | `true` для неявного SSL/TLS (обычно порт 465); вместе с `SMTP_STARTTLS=true` включать нельзя |
| `INQUIRY_EMAIL` | Куда получать заявки; по умолчанию `info@hermetica.su` |

Например, для локального запуска добавьте значения в **Run → Edit Configurations → Environment variables** в IntelliJ. Типовая пара параметров — порт `587`, `SMTP_STARTTLS=true`, `SMTP_SSL=false`; либо порт `465`, `SMTP_STARTTLS=false`, `SMTP_SSL=true` — используйте только то, что требует ваш провайдер. Не вписывайте пароль в `application.yml`, не коммитьте `.env` и не отправляйте пароль в чат. Значения SMTP нужно взять в панели управления именно того почтового сервиса, где обслуживается `info@hermetica.su`; они не совпадают с адресом сайта и не могут быть угаданы из проекта.

## Поведение формы

- При успешном ответе SMTP пользователь видит подтверждение отправки.
- При ошибке соединения/авторизации письмо не считается отправленным и сайт показывает телефон и корпоративную почту для связи.
- Заявки и их содержимое не записываются в журнал приложения. Для автоматической отправки в CRM нужна отдельная интеграция.
- Текст письма включает имя, контакт, организацию (если указана), запрос, страницу отправки и время.

Используется стандартная интеграция `JavaMailSender` Spring Boot. Таймауты SMTP ограничены пятью секундами, чтобы форма не зависала при недоступном почтовом сервере.
